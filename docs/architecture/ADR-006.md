# ADR-006: Divisional Charts (Varga) Engine & Varga Registry

## Status
**ACCEPTED** (Date: 2026-08-06)

## Context
Divisional charts (Vargas) are fundamental in Vedic astrology for fine-grained analysis of specific life areas (e.g. D9 Navamsa for spouse/dharma, D10 Dasamsa for career/karma, D60 Shastiamsa for past karma).

Calculating Vargas independently by re-evaluating ephemeris positions leads to code duplication and calculation drift.

## Decision
We decide to implement:
1. **Single Source of Truth Astronomy**: Every Varga calculator implements `IVargaCalculator` and reads exclusively from `CalculationContext.astronomical_state`. Zero ephemeris longitudes are re-calculated.
2. **Dedicated `VargaRegistry`**: A global `VargaRegistry` manages the 14 standard Parashari divisional chart calculators:
   - D2 (Hora), D3 (Drekkana), D7 (Saptamsa), D9 (Navamsa), D10 (Dasamsa), D12 (Dwadasamsa), D16 (Shodasamsa), D20 (Vimsamsa), D24 (Chaturvimsamsa), D27 (Bhamsa), D30 (Trimsamsa), D40 (Khavedamsa), D45 (Akshavedamsa), D60 (Shastiamsa).
3. **Stateless Mathematical Pure Functions**: Each Varga calculator provides pure mathematical sign division logic without external dependencies or framework side-effects.

## Consequences

### Positive
- **Independent Testability**: Each of the 14 Varga calculators is individually unit-testable against standard astronomical reference tables.
- **Microsecond Latency**: Pure mathematical division completes in $<0.01\text{ ms}$ per chart.
- **100% Backward Compatibility**: Core API endpoints remain unchanged while Varga calculations are accessible cleanly via the registry.
